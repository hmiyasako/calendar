# サブエージェント活用パターン

## 並行開発パターン

複数の独立したタスクを同時に実行する場合、サブエージェントを並行起動して開発速度を向上させる。

### 例: フロントエンド + バックエンド同時開発

```
Task 1 (Backend Agent):
- Express + SQLite API実装
- ルート定義、DB設定

Task 2 (Frontend Agent):
- React SPA実装
- コンポーネント、フック作成
```

## サブエージェントの使い分け

| タイプ | 用途 |
|--------|------|
| `general-purpose` | 複雑な実装タスク、マルチステップ作業 |
| `Explore` | コードベース調査、ファイル検索 |
| `Plan` | 設計・計画立案 |
| `Bash` | Git操作、コマンド実行 |

## バックグラウンド実行

```typescript
// run_in_background: true で非同期実行
// 出力は /tmp/claude/.../tasks/xxx.output に保存
// Read または tail で進捗確認可能
```

## ベストプラクティス

1. **独立したタスクは並行実行**
   - フロントとバックを同時に
   - テストとリント並行

2. **依存関係がある場合は順次実行**
   - DB設計 → API実装 → フロント連携

3. **詳細なプロンプトを提供**
   - ファイルパス、技術スタック、要件を明確に

4. **完了待ちの間に他の作業**
   - README作成、.gitignore設定など
